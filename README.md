# POE Recorder OBS Plugin

## Introduction

An OBS Plugin for recording Path of Exile sessions. Automatically starts recording when entering a zone, and restarts the recording upon player death.

AI (Co-Pilot) was used in the development of this plugin.

This plugin was created using the [OBS Plugin Template](https://github.com/obsproject/obs-plugintemplate) provided by [OBSProject](https://github.com/obsproject).
